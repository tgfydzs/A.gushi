# 修炼体系参考

苍云大陆修炼境界从低到高：炼气期 → 筑基期 → 金丹期 → 元婴期 → 化神期 → 渡劫期 → 大乘期。每境分初、中、高三段。

| 突破 | 正常资质所需时间 | 寿元 | 备注 |
|------|----------------|------|------|
| 炼气初期→中期 | 数月苦修 | 百岁 | 入门阶段，多数散修终老于此 |
| 炼气中期→后期 | 半年到一年 | 同上 | 外门弟子平均水平 |
| 炼气后期→圆满 | 一年以上 | 同上 | 筑基前的准备 |
| 炼气→筑基 | 数年积累 + 契机或筑基丹 | 二百岁 | 分水岭——散修极难获得筑基丹 |
| 筑基→金丹 | 十数年苦修 + 宗门资源 | 五百岁 | 金丹可开宗立派 |
| 金丹→元婴 | 数十年 + 大机缘 | 千年 | 当世万中无一 |
| 元婴→化神 | 百年以上 + 天劫 | 三千年 | 苍云大陆不超过十人 |
| 化神→渡劫 | 数百年积累 + 生死关 | 五千年 | 渡劫成功则入大乘，失败则身死道消或转修散仙 |
| 渡劫→大乘 | 千年一遇 | 万载 | 已千年未现于苍云大陆 |

特殊说明：
- 天才资质可缩短至1/3时间
- 有丹药（筑基丹、凝丹散等）辅助可大幅加速
- 灵气持续衰减，现在的突破难度比上古时期大了数倍
- 跨越一个大境界必有天劫——越往后越凶险
- 「无法估量」实力的角色（如三位隐世渡劫老祖），修炼速度不遵循常规
