# 世界层数据结构，使用、创建、注意点
## 据文件使用json格式
## 结构示例：
    {
        "规则组1": {
            "世界规则列表": [],
            "世界状态列表": [],
            "世界演变规则列表": [],
            "世界知识列表": [],
            "世界地点列表": {}
        }
    }
## 最外层保持标准字段，内部为列表，列表内部遵循单一语义单元（描述一件事情），为后续可能的向量化留足空间
## 一个文件存多个组


# 字段解释

## 规则组：
### 该字段不会参与到引擎中，无实际意义，是编辑时的区分辨识符


## 世界规则列表（list）
### 用途：世界基本规则，是既定事实，类似数学，会就是会不会就是不会。
### 通常是存一些定死的，是世界基本规则，但又需要额外声明的（ai理解时无法直接确定的事物），例如：
    "世界规则列表": ["战力到达筑基初期，力量有百鼎之力", "实力划分：锻体、练气、筑基、金丹、元婴、化神、炼虚、合体、大乘、渡劫"]


## 世界状态列表（list）
### 用途：存储当前世界的状态，一部分来自于通过 世界演变规则列表 中 依据 判断的世界状态，另一部分来自于玩家开放性创造的世界状态
    "世界状态列表": ["没人发现大主教的秘密", "世人依然认为所谓蓬莱仙岛是口口相传的传说"]
### 通过下面的 世界演变规则列表 更新后
    "世界状态列表": ["大主教的秘密被发现了，已经下令追杀玩家", "蓬莱仙岛竟然真的出现了，只不过是在口传位置的超高空显现"]



# 世界演变规则列表（list）
### 用途：剧本节点，当剧情发展，旁白或者世界演变层触发依据，世界将进入变化之后
### 要写明变化之前、依据（依据一般为某件事情，或者时间节点）、变化之后的规则。世界演变时会参考这个来判断当前世界状态
### 类似一个剧本触发节点，里面预先设定了时间线，该字段仅传入导演层，供旁白使用
    "世界演变规则列表": ["大主教原本是这个世界公认的神圣帝国领导者，当大主教的秘密被处理后，大主教会追杀该人，同时逐渐显现原型", "蓬莱仙岛口传的位置并没有那座岛，当到达一千百年一轮回的开始，蓬莱仙岛会在口传位置的超高空显现"]
### 导演层会根据当前所处时间节点，和规则列表中的依据，来触发旁白叙事



## 世界知识列表（list）
### 用途：世界级别，最杂的列表，该列表会不断演变


## 世界地点列表（dict）
### 用途：常规游戏中的地图概念，需要举例全部地图位置，需要足够详细
### 因为有从属关系，因此需要使用字典嵌套，依次细化
    "世界地点列表": {
        "天玄大陆": {
            "玄月皇朝": {
                "上京": {
                    "东城区":{
                        ...
                    }
                }
            }
        }
    }
