# 世界层 (B1_worldState) 配置说明

## global.json 结构

```json
{
    "世界观名称": {

        "游戏开始时间": "故事开始的游戏内时间字符串",
        "时间格式": "时辰制 | 24小时制",

        "世界规则列表": [
            "修炼体系定义、势力关系、世界基本法则等不可改变的事实。每条一个字符串，LLM会参考这些规则判断事件合理性。"
        ],

        "世界状态列表": [
            "当前世界中的公开状态/趋势。每条一个字符串，是正在发生的事实。会随N9a规则触发而动态增删。"
        ],

        "世界演变规则列表": [
            "后台世界演变的触发条件+后果。每条包含前提条件和结果描述。N9a引擎会逐条判断依据是否成立+时间是否足够。"
        ],

        "世界知识列表": [
            "隐藏背景设定，仅LLM可参考。玩家正常情况下不应知道的秘密、历史真相。"
        ],

        "世界地点列表": {
            "大陆名": {
                "区域名": {
                    "具体地点名": "地点描述",
                    "子地点名": {
                        "更细的地点": "描述"
                    }
                }
            }
        }
    }
}
```

## 字段说明

| 字段 | 是否必填 | 说明 |
|------|---------|------|
| 游戏开始时间 | 是 | 格式自定，建议含年/季节/时辰 |
| 时间格式 | 是 | `时辰制`=12时辰，`24小时制`=标准时间 |
| 世界配置 | 否 | 代码行为参数：距离阈值/心跳间隔/NPC上限等（见下方说明） |
| 世界规则列表 | 是 | 每条≤100字，直接作为LLM参考 |
| 世界状态列表 | 是 | 运行时动态变化，初始写世界现状 |
| 世界演变规则列表 | 是 | N9a引擎逐条判断，格式：前提 → 结果 |
| 世界知识列表 | 否 | 隐藏设定，不给玩家看 |
| 世界地点列表 | 是 | 地点树以`·`分隔层级，每层可无限嵌套 |

## 世界配置说明

`世界配置` 节驱动代码行为，无需修改代码即可适配不同世界。所有字段均有默认值，可只填需要的。

| 配置项 | 默认值 | 作用 |
|--------|--------|------|
| `NPC_附近距离_段` | 3 | 附近NPC距离阈值（add_npc用） |
| `NPC_关联距离_段` | 8 | 关联NPC距离阈值（add_related_npc用） |
| `事件_最小上下文长度` | 2 | 防新事件死循环的最小上下文条数 |
| `心跳间隔_小时` | 12 | 后台心跳触发间隔（游戏时间小时） |
| `NPC_观察上限` | 20 | NPC Observation 表最大条数 |
| `NPC_记忆上限` | 30 | NPC Memory 表最大条数 |
| `NPC_待推理上限` | 10 | NPC PendingReasoning 表最大条数 |
| `玩家初始数据` | — | 玩家JSON文件路径（相对 BASE_PATH） |

## 地点树注意事项

- 地点层级以`·`（中文点号）分隔
- LLM通过地点的LCA（最近公共祖先）判断距离
- 叶子节点可以是字符串（简单描述）或对象（包含子地点）
- 嵌套深度不限，但建议不超过5层
